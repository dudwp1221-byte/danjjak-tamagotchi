# 아트 퀄리티 업 플랜 (펫 스프라이트 제외)

> **후속 문서**: 무료 에셋 실조사 결과 + 코덱스 제작 스펙은 [UI-ART-BRIEF.md](./UI-ART-BRIEF.md) 참고.

> 현재 상태: 펫 = WebP 스프라이트(양호) / 방·배경 = CSS 그라데이션 /
> 가구·악세서리·상태 오버레이 = **OS 이모지 폰트** / 아이콘 = SVG 일부 + 이모지 다수.
> 가장 큰 퀄리티 저하 요인은 ①이모지 의존(플랫폼마다 다르게 보임, 게임 아트와 톤 불일치)
> ②방/무대가 단색 그라데이션이라 "방"처럼 안 보임 ③화면별 디자인 토큰 불일치.

## A. Claude(코드/CSS/SVG)가 직접 할 수 있는 것 — 비용 0, 즉시

| 항목 | 내용 | 기대 효과 |
| --- | --- | --- |
| 방 씬 CSS 리디자인 | 벽지 패턴(repeating-gradient), 나무 바닥결, 걸레받이, 창문 밖 시간대별 하늘(아침/노을/밤), 벽 그림자·조명 레이어 | 이미지 없이도 "방" 느낌 — 최대 체감 |
| 디자인 토큰 정리 | 색·라운드·그림자·간격을 CSS 변수로 통일 (지금 화면마다 제각각) | 전체 UI 일관성 |
| 가구 SVG 1차 교체 | 이모지 가구 → 직접 그린 인라인 SVG(공통 팔레트, 픽셀아트풍). 십수 종은 수작업 가능 | 가장 눈에 띄는 이모지 제거 |
| 마이크로 인터랙션 | 버튼 탭 스프링, 모달 진입 애니메이션, 탭 전환 이징, 카드 호버 | "싸구려 웹" 느낌 제거 |
| 이펙트 고도화 | 레벨업/진화/오라 파티클을 CSS·SVG로 리치하게 (이미 일부 있음) | 보상 체감 |
| 상점/도감 카드 레이아웃 | 그리드 정돈, 등급(명예/프리미엄) 시각 언어 통일 | 정보 위계 |

## B. 코덱스(또는 이미지 생성 AI)에 맡기면 더 좋은 것

코드 에이전트보다 "그림 자체"가 필요한 영역. 이미지 생성(ChatGPT 이미지/미드저니 등)으로 뽑고,
코덱스에는 대량·반복 통합 작업을 맡기는 구성이 효율적.

| 항목 | 왜 AI 이미지/코덱스인가 |
| --- | --- |
| 방 테마 배경 일러스트 (17종) | bg_* 테마들이 지금 그라데이션 한 장. 테마당 1장씩 픽셀아트/수채 배경을 생성해 교체하면 상점 컬렉션 가치가 확 오름. 펫 스프라이트와 톤 맞춘 프롬프트 세트만 정하면 양산 가능 |
| 가구 스프라이트 시트 (15종+) | 손 SVG보다 퀄리티 상한이 높음. 32/48px 픽셀아트로 통일 생성 |
| UI 아이콘 세트 (액션 6종·탭 5종·메뉴) | 이모지 아이콘 전면 교체용. 스타일 가이드 고정 후 일괄 생성 |
| 타이틀 로고/앱 아이콘 | 현재 텍스트+이모지. 브랜드 얼굴 |
| 대량 통합 작업 | 생성된 에셋 수십 장을 manifest 만들고 코드에 일괄 연결하는 반복 작업은 코덱스에 병렬로 맡기기 좋음 (스프라이트 최적화 파이프라인은 이미 sharp 사용 중) |

## C. 무료 에셋(GitHub/오픈소스)으로 해결 가능한 것

| 에셋 | 라이선스 | 용도 |
| --- | --- | --- |
| **Twemoji** (github.com/twitter/twemoji) 또는 **OpenMoji** | CC-BY 4.0 / CC BY-SA 4.0 | 남는 이모지를 SVG로 렌더 → **Windows/모바일에서 똑같이 보임**. 이모지 톤 불일치의 즉효약. 빌드에 필요한 것만 복사 |
| **Kenney Game Assets** (kenney.nl, github mirror) | CC0 | UI 패널·버튼·아이콘, 가구/인테리어 팩. 출처 표기도 불필요 |
| **Galmuri** (github.com/quiple/galmuri) | SIL OFL | 한글 픽셀 폰트 — 다마고치 레트로 무드에 최적. 숫자/타이머 표시에만 써도 효과 큼 |
| **Pretendard** (github.com/orioncactus/pretendard) | SIL OFL | 본문 UI 폰트 정리 (시스템 폰트 대비 일관성) |
| itch.io CC0 인테리어 팩 (예: "Pixel Interior" 계열 CC0 검색) | CC0 확인 필수 | 방 벽지/바닥/가구 타일 |

## 권장 순서 (체감 대비 비용)

1. **Twemoji SVG 도입** — 반나절, 전 플랫폼 통일 (무료 에셋, Claude가 바로 가능)
2. **방 씬 CSS 리디자인 + 디자인 토큰** — Claude 직접, 하루
3. **Galmuri/Pretendard 폰트 적용** — 1시간
4. **방 테마 배경 17종 AI 생성 → 교체** — 이미지 생성 + 코덱스 통합
5. **가구/아이콘 스프라이트 세트 생성 → 교체** — 이미지 생성 + 코덱스 통합
6. Kenney UI 프레임은 4~5와 병행 검토
