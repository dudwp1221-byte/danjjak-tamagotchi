# 단짝 다마고치 — 개발 로드맵

> 회사에서 몰래 키우는 단짝 다마고치 🥚
> React + TypeScript + Vite 기반 멀티플레이 웹 게임

## 게임 컨셉

사무실에서 몰래 키우는 가상 펫 다마고치. 직접 그린 펫을 키우고,
스탯을 관리하며, 들킬 것 같으면 "패닉 버튼"으로 가짜 업무 화면을 띄운다.
친구들과 Firebase로 연동해 서로의 펫을 구경할 수 있다.

## 기술 스택

| 영역 | 선택 | 비고 |
| --- | --- | --- |
| 프레임워크 | React 19 (함수형 + 훅) | |
| 언어 | TypeScript | |
| 빌드 도구 | Vite | |
| 드로잉 | HTML Canvas 2D API | 외부 라이브러리 없이 직접 구현 |
| 멀티플레이 | Firebase Realtime Database | Phase 4에서 도입 |
| 상태 저장(로컬) | localStorage | Phase 2에서 도입 |

## 폴더 구조

```
src/
├─ components/          # 공용 UI 컴포넌트 (Button, Modal 등)
├─ features/            # 기능 단위 모듈
│  ├─ pet-creator/      # 1. 캔버스 드로잉으로 펫 만들기
│  ├─ pet-status/       # 2. 스탯 관리 (배고픔/기분/청결/잠)
│  ├─ panic-mode/       # 3. 가짜 업무 화면 패닉 버튼
│  └─ multiplayer/      # 4. Firebase 멀티플레이
├─ hooks/               # 공용 커스텀 훅 (useInterval 등)
├─ types/               # 공용 타입 정의 (pet.ts)
├─ utils/               # 유틸 함수 (스탯 계산 등)
└─ assets/              # 정적 리소스
```

## ⭐ 핵심: 종족 · 분기 진화 · 분류 체계 (디지몬식)

이 게임의 정체성 — **직접 그려서 랜덤으로 얻는 펫**, 그리고 **다양한 형태로 갈라지는 진화**.

- **랜덤 획득(가챠)**: 펫을 그리면 희귀도(일반/레어/에픽/전설)별 **랜덤 시작 형태**
  획득 + 두근두근 리빌 연출 (`features/reveal/`)
- **분기 진화(트리)**: 한 캐릭터가 **조건/선택에 따라 여러 갈래로** 진화.
  **118개 계통 · 818개 형태**, 일부 **3갈래 분기**, **특수 진화**(진화의 돌/스탯/시간·계절 조건).
  예: 도롱이 → (불도마/물도마/바람도마) → … → 염제룡/해신룡/풍신룡, 또는 💠로 공룡신
  (`utils/species.ts`, `features/evolution/Evolve.tsx`)
- **합체 진화(DNA 합체)**: 보관함의 두 펫(레벨 8↑)을 합쳐 전설 합체 형태로
  (속성 조합 → 성광/암흑/강철/혼돈 합체체) (`features/fusion-evo/`)
- **속성 대결**: 친구 펫과 속성 상성+레벨로 단판/랭킹전(토너먼트) (`features/battle/`)
- **계통별 스토리 퀘스트**: 계통마다 고유 3막, **3막은 진화 갈래에 따라 분기**
  (`utils/quests.ts` `LINE_QUESTS`, `branchStory`)
- **합체 연출**: 두 펫이 합쳐지는 애니메이션 + 결과 공개 (`features/fusion-evo/`)
- **분기 조건**: 일부 갈래는 스탯 조건(기분/청결/기운 70↑)을 충족해야 선택 가능
- **명예 점수**: 랭킹전 누적 점수 + 티어(브론즈~다이아) (`utils/storage.ts` `honorTier`)
- **히든 종족(각성)**: 궁극체가 **형태마다 다른 숨겨진 조건**을 달성해야 각성 —
  **사신수(4)·사흉수(4)·12지신(12)·4대천사(4)·7대 죄악마(7)** + 연출/설화
  (`features/awaken/`, `utils/awaken.ts`, 도감 히든 섹션)
  - 조건은 **은근한 암시(수수께끼)**로만 노출, 충족 전엔 ??? / 🔒
  - 펫의 **외형·속성·성격·상태·계절·태생**에 따라 갈 수 있는 히든이 다름
    (예: 사신수=계절+속성+완벽양육, 사흉수=방치된 상태, 천사/악마=성격,
    12지신=태어난 달, 죄악마 탐욕=코인 축적 등)
- **초각성**: 사신수 4종을 모두 발견하면 대장 **황룡(초월체/tier4)**으로 초각성
- **도감 보상**: 수집률 25/50/75/100% 마일스톤 코인 보상 + 진행 바
- **다축 분류**: 각 형태가 **레벨(성장기·성숙기·완전체·궁극체) × 타입(6대 + 세부형)
  × 원소 속성(불·물·풀·바람·땅·빛·어둠·무)** 을 가짐 (속성은 이름·테마로 자동 분류)
- **속성 효과·상성**: 불/어둠=경험치↑, 풀=코인↑, 물/땅/빛=감소 느림, 바람=소량;
  상성 **물>불>풀>땅>바람>물**, **빛↔어둠** (`attributeBeats`)
- **도감**: 계통별 진화 트리를 수집·열람 (`features/dex/`)
- **여러 마리 보관함**: 여러 펫 전환, 합성은 새 식구 추가 (`features/roster/`)
- **졸업 엔딩**: 만렙 시 독립 → 명예의 전당 (`features/graduation/`)

## 추가 구현된 시스템 (강화 업데이트)

핵심 4단계 외에 게임성을 높이는 시스템들을 구현했다 (자세한 아이디어는
[IDEAS.md](./IDEAS.md) 참고).

- **펫 진화/성장** — 케어로 경험치·레벨 획득, 아기→청소년→어른→전설 단계
  (`utils/progression.ts`)
- **컨디션 표현** — 스탯에 따라 펫 위에 얼룩/zzz/반짝임 오버레이
  (`utils/expression.ts`, `components/PetAvatar.tsx`)
- **재화·상점** — 코인으로 악세서리(꾸미기)·간식(회복) 구매 (`features/shop/`)
- **업적·출석** — 11종 업적 자동 해금, 일일 연속 출석 보상
  (`utils/achievements.ts`)
- **상사 이벤트** — 랜덤 등장, 제한시간 내 숨기기 (`hooks/useBossEvent.ts`)
- **자랑 카드** — 펫 정보를 이미지 카드로 합성·공유 (`utils/shareCard.ts`)
- **알림** — 자리 비울 때 케어 알림 + 탭 제목 배지
  (`hooks/useCareNotifications.ts`, `hooks/useTabBadge.ts`)
- **온보딩** — 첫 실행 시 단계별 조작 안내 (`features/onboarding/`)
- **미니게임 2종** — 간식 받기(`CatchGame`) + 가위바위보(`RockPaperScissors`)
- **펫 성격** — 5종 기질이 스탯 감소 속도에 영향 (`utils/personality.ts`)
- **다이어리** — 레벨업·업적 등 성장 기록 타임라인 (`features/diary/`)
- **일일 미션** — 매일 갱신되는 3종 미션 + 코인 보상 (`features/missions/`)
- **펫 말풍선** — 상태/성격에 따른 대사 (`utils/petLines.ts`)
- **방 배경 꾸미기** — 상점 배경 구매·착용 (`utils/items.ts`의 background)
- **시즌 테마** — 계절별 인사 + 시즌 한정 아이템 (`utils/season.ts`)
- **효과음 확장** — 레벨업/업적/상사 등장/코인 사운드 (`utils/sound.ts`)
- **업적 보상** — 달성 시 코인 지급, 총 17종 업적
- **펫 합성/교배** — 내 펫 + 친구 펫 그림을 합쳐 2세 입양 (`features/fusion/`)
- **랭킹/명예의 전당** — 내 펫·친구 점수 순위 (`features/ranking/`)
- **퀘스트 스토리** — "단짝과의 이야기" 6화 순차 진행 (`features/quest/`, `utils/quests.ts`)
- **라이트/다크 테마** — CSS 변수 기반 전환 (`utils/storage.ts`의 `applyTheme`)
- **복귀 환영 요약** — 자리 비운 시간/상태 안내 (`features/welcome/`)
- **콤보 보너스** — 모든 스탯 80↑ 유지 시 주기적 보상 + 배지
- **QoL** — 펫 이름 변경, 튜토리얼 다시 보기, 자동 숨기기 토글 (설정)
- **게임 시계·달력** — 현실과 별개로 게임 시간이 빠르게 흐름 (게임 1일 = 실제 약
  27.6분, 1년 = 365일 = 실제 7일). 헤더에 게임 연·월·시각 + 시간대(새벽/낮/저녁/밤/
  한밤중) 표시, 밤이 깊을수록 무대가 어두워짐 (`utils/gametime.ts`)
- **시간·계절 진화/각성 조건** — 일부 분기는 특정 시간대·계절에만 진화(밤올빼미=밤,
  빙판펭귄=겨울, 용암불사조=여름). 사신수는 계절+속성(청룡=봄/주작=여름/백호=가을/
  현무=겨울), 12지신은 "태어난 달"로 각성 (`utils/awaken.ts`)
- **시간대·계절 대사** — 펫이 밤/계절에 따라 다른 말풍선을 띄움 (`utils/petLines.ts`)

상태 관리는 `hooks/usePet.ts`로 중앙화했다.
테스트는 `*.test.ts` (vitest, `npm test`) — 스탯·성장·업적 로직 22개 케이스.

## 개발 순서 요약

```
Phase 0 (세팅) → Phase 1 (펫 만들기) → Phase 2 (스탯 관리)
   → Phase 3 (패닉 모드) → Phase 4 (멀티플레이) → Phase 5 (폴리싱)
```

각 Phase는 독립적으로 동작 가능하도록 만들어 단계마다 플레이 가능한
빌드를 확보하는 것을 목표로 한다.
