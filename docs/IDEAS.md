# 단짝 다마고치 — 강화 아이디어 모음 💡

게임을 더 재미있고, 더 "단짝 다마고치답게" 만들 아이디어들.
우선순위: ⭐ 핵심(임팩트 큼) · 🔸 추천 · 🔹 여유될 때

---

## 1. 코어 게임플레이 강화

- ⭐ **펫 진화/성장 단계** — 알 🥚 → 아기 → 청소년 → 어른. 함께한 일수와
  평균 컨디션에 따라 모습이 바뀐다. 키우는 동기 부여의 핵심.
- ⭐ **컨디션에 따른 펫 그림 변형** — 더러우면 그림 위에 얼룩, 졸리면 눈에
  `zzz`, 행복하면 반짝임. 내가 그린 그림을 그대로 살리면서 상태를 표현.
- 🔸 **방치 패널티 / 가출** — 오래 방치하면 펫이 토라지거나 잠시 사라졌다
  돌아온다(완전 죽음은 부담스러우니 "삐짐" 정도로).
- 🔸 **액션 쿨다운 & 과식 패널티** — 배부른데 계속 먹이면 청결/기분이 깎임.
  단순 연타 방지 → 전략적 케어 유도.
- 🔸 **하루 루틴/일과** — 아침엔 밥, 점심엔 산책, 밤엔 잠처럼 시간대별
  추천 케어. 실제 시계와 연동.
- 🔹 **미니게임** — 펫과 공놀이, 간식 받아먹기 등. 기분 회복 + 재미.
- 🔹 **컨디션 콤보 보너스** — 4스탯 모두 80↑ 유지 시 "최상 컨디션" 버프.

## 2. "몰래" 컨셉 강화 (이 게임의 정체성 ⭐)

- ⭐ **패닉 자동 발동** — 탭에서 포커스가 벗어나면(`visibilitychange`,
  `blur`) 자동으로 가짜 엑셀로 전환. 진짜 "몰래" 느낌.
- ⭐ **상사 접근 이벤트** — 가끔 "상사가 다가옵니다!" 경고 → 제한 시간 안에
  숨기지 못하면 패널티. 긴장감 있는 핵심 재미 요소.
- 🔸 **가짜 화면 종류 다양화** — 엑셀 외에 가짜 메일함, 가짜 코드 에디터,
  가짜 회의록. 설정에서 선택.
- 🔸 **위장 모드(미니 위젯)** — 평소엔 화면 구석 작은 위젯으로만 떠 있고,
  클릭하면 펼쳐짐. 항상 들킬 위험을 줄임.
- 🔸 **무음 강제 + 진동/시각 알림** — 회사 컨셉에 맞게 소리 대신 깜빡임으로
  알림. (이미 기본 음소거 → 확장)
- 🔹 **"근무 시간" 모드** — 9~18시엔 패닉이 더 자주 필요한 하드 모드.

## 3. 펫 만들기 / 꾸미기 확장

- ⭐ **그리기 도구 강화** — 채우기(페인트통), 도형(원/사각), 스포이드,
  대칭 모드(좌우 자동 대칭으로 캐릭터 쉽게), 스티커.
- 🔸 **레이어 / 다중 undo·redo** — 지금은 단순 undo만. redo와 레이어 추가.
- 🔸 **펫 꾸미기(악세서리)** — 모자, 리본, 안경 등을 그림 위에 덧입히기.
- 🔸 **배경/방 꾸미기** — 펫이 사는 작은 책상/방을 꾸민다.
- 🔹 **펫 갤러리** — 내가 만든 역대 펫들을 보관·감상.
- 🔹 **그림 불러오기/이미지 업로드** 후 다듬기.

## 4. 멀티플레이 / 소셜 (Phase 4 본격화)

- ⭐ **친구 펫 구경 + 방문 선물** — 친구 펫에게 간식/쓰다듬기 보내기,
  답방 알림. 소셜 리텐션의 핵심.
- 🔸 **펫 자랑 카드 공유** — 펫 + 함께한 일수 + 컨디션을 이미지 카드로
  만들어 메신저에 공유(바이럴).
- 🔸 **협동 돌봄** — 친구와 한 펫을 같이 키우기(자리 비울 때 대신 케어).
- 🔹 **랭킹** — "가장 오래 키운 펫", "최고 컨디션 유지" 주간 랭킹.
- 🔹 **펫 교류/교배** — 두 펫의 그림을 합성한 새 펫(가벼운 재미).
- 🔹 **방명록/이모지 리액션** — 친구 펫에 남기는 한마디.

## 5. 진행 / 성장 메타 시스템

- 🔸 **재화 & 상점** — 케어로 코인 획득 → 먹이/악세서리/배경 구매.
- 🔸 **도전 과제(업적)** — "7일 연속 돌보기", "컨디션 100 달성" 등 배지.
- 🔸 **일일 출석 보상** — 매일 접속 시 보상 → 리텐션.
- 🔹 **펫 다이어리/타임라인** — 성장 기록을 자동으로 일지처럼 남김.

## 6. 알림 / 리텐션

- ⭐ **브라우저 알림(웹 푸시)** — "펫이 배고파해요" 알림. 자리 비운 사이
  돌아오게 만드는 강력한 장치.
- 🔸 **탭 타이틀/파비콘 배지** — 케어 필요 시 탭 제목에 `(!)` 표시.
- 🔹 **이메일/일일 요약** — 오늘 펫 상태 요약(멀티플레이 단계와 함께).

## 7. 품질 / 기술 / 접근성

- ⭐ **PWA(설치형 앱)** — 홈 화면에 설치, 오프라인 지원. 회사 PC에서도
  앱처럼. 다마고치 앱 경험에 잘 맞음.
- 🔸 **데이터 백업/복원** — 펫 데이터 내보내기(JSON)·가져오기. 기기 이동.
- 🔸 **테스트** — 스탯 계산(`stats.ts`)·저장(`storage.ts`) 단위 테스트.
- 🔸 **상태 관리 정리** — 펫 상태 로직을 커스텀 훅(`usePet`)으로 분리.
- 🔹 **다국어(i18n)**, **다크/라이트 테마 선택**.
- 🔹 **효과음/배경음 에셋 정교화**, 햅틱(모바일 진동).

## 8. 콘텐츠 / 세계관 (있으면 풍성해짐)

- 🔹 **펫 성격(랜덤 기질)** — 먹보/잠꾸러기/애교쟁이 등. 같은 케어도 반응 차이.
- 🔹 **계절/이벤트** — 크리스마스 모자, 명절 한정 먹이 등 시즌 한정 콘텐츠.
- 🔹 **스토리/대사** — 펫이 가끔 말풍선으로 한마디.
