# 🎨 도트(픽셀 아트) 스프라이트 작업 브리프 — for Codex

> 이 문서 하나로 작업 맥락을 파악할 수 있게 정리했습니다.
> 그릴 대상 전체 목록은 **[`sprite-manifest.json`](./sprite-manifest.json)** / **[`sprite-manifest.csv`](./sprite-manifest.csv)** 참고.

## 1. 게임 한눈에

**단짝 다마고치** — 회사에서 몰래 키우는 가상 펫 게임 (React 19 + TypeScript + Vite).
플레이어가 펫을 그리면 희귀도별 종족을 얻고, **118계통 · 818형태**의 디지몬식 분기 진화·합체·각성을 한다.
자세한 맥락은 [`ROADMAP.md`](./ROADMAP.md).

## 2. 지금 펫이 화면에 그려지는 방식 (= 우리가 바꿀 곳)

- 현재 모든 종족이 **플레이어가 캔버스로 그린 그림(`imageDataUrl`, PNG dataURL) + 종족 색 오라(aura)** 로만 표현됨.
  종족별 **고유 외형 스프라이트는 아직 없음.**
- 렌더 컴포넌트: **`src/components/PetAvatar.tsx`** — 핵심은 `<img src={imageDataUrl}>`.
  여기에 종족 오라(`pa-aura`), 색조(`pa-tint`), 악세서리, 컨디션 오버레이가 합성됨.

## 3. 아트 방향 (확정)

- **종족(형태)별 고유 픽셀 도트 스프라이트.**
- 플레이어가 그린 그림은 **"가장 닮은 종족으로 매칭"** 하는 입력으로 쓰고, 실제 표시는 종족 도트 스프라이트로 가는 방향
  (그림→유사종족 매칭). ※ 매칭 로직은 별도 작업 — 이번 도트 작업의 1차 목표는 **스프라이트 자산 자체**.

## 4. 그릴 대상 — 818형태

전체 목록·속성은 매니페스트 파일에 있음. 각 형태(`Form`)가 가진 필드:

| 필드 | 의미 | 값 |
| --- | --- | --- |
| `id` | 고유 ID (**파일명으로 사용**) | 예: `liz_fire2` |
| `name` | 한글 이름 | 예: 화염룡 |
| `line` | 소속 계통(진화트리) | 118종 |
| `tier` / `tierName` | 진화 단계 0~4 | 성장기·성숙기·완전체·궁극체·초월체 |
| `family` | 6대 대분류 | 생물형 / 인간형 / 기계형 / 신성·악마형 / 사물·인공물형 / 혼합·이형형 |
| `type` | 세부 타입 | 파충류형·용형·조류형·천사형 등 |
| `attribute` | 원소 속성(색 테마 핵심) | fire/water/grass/wind/earth/light/dark/neutral |
| `rarity` | 희귀도 | common/rare/epic/legendary |
| `emoji` | 현재 대표 이모지 (**디자인 출발점 힌트**) | 예: 🐉 |
| `aura` | 종족 발광 색 (HEX) | 예: `#f97316` |
| `hidden` | 히든(각성 전용) 여부 | 32종 (사신수·사흉수·12지신·4대천사·7대 죄악마·황룡) |

**속성별 색 가이드** (게임 내 정의, 팔레트 기준): 불 `#fb923c` / 물 `#38bdf8` / 풀 `#22c55e` / 바람 `#5eead4` / 땅 `#a16207` / 빛 `#fcd34d` / 어둠 `#a78bfa` / 무 `#9ca3af`.

분포 참고: tier0 111, tier1 223, tier2 223, tier3 260, tier4(황룡) 1 · 히든 32.

## 5. 스프라이트 스펙 (권장 — 코덱스가 더 나은 안 있으면 제안 환영)

- **캔버스**: 정사각 투명 배경 PNG. 권장 **64×64** (또는 48×48). 단계가 올라갈수록 화면에선 더 크게 보임(코드가 scale 처리하니 자산은 동일 캔버스 OK).
- **스타일**: 제한 팔레트(형태당 4~8색), 또렷한 외곽선, 정면~3/4 뷰, 다마고치풍의 둥글고 귀여운 톤.
- **일관성**: `attribute`로 메인 팔레트, `family`/`type`로 실루엣(파충류형·조류형·용형·천사형…), `tier`가 높을수록 디테일·위엄 ↑, `rarity`가 높을수록 화려함.
- **계통 일관성**: 같은 `line`은 같은 캐릭터의 진화처럼 보이도록 모티프 계승.
- **출력 위치/이름**: `public/sprites/{id}.png` (파일명 = `Form.id`). 예: `public/sprites/hid_azure.png`.

## 6. 통합 지점 (스프라이트를 다 만든 뒤)

`PetAvatar.tsx`에서 종족 스프라이트가 있으면 `imageDataUrl` 대신(또는 토글로) `/sprites/{species.id}.png`를 보여주도록 분기.
오라/색조/오버레이 합성 로직은 그대로 재사용 가능. (이번 자산 작업 후 별도 PR로 연결 권장.)

## 7. 작업 분할 제안

규모가 크니 단계적으로:
1. **계통 대표 + tier별 스타일 가이드** 먼저 (예: `liz` 계통 도롱이→화염룡→…) 한 줄로 톤 확립.
2. 속성×family 조합 템플릿화 → 나머지 형태로 확장.
3. **히든 32종**(사신수=계절신수, 12지신, 천사/악마)은 개별 디자인 가치가 높으니 정성 들이기 — `lore` 필드에 설화 있음.
