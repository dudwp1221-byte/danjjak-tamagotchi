# 🎨 이미지 생성 프롬프트 32장 (ChatGPT 이미지 생성용)

> 사용법: 한 장씩 아래 프롬프트를 복붙해서 생성 → 마음에 들면 저장 →
> **표시된 파일명으로** `public/themes/`(배경) 또는 `public/deco/`(악세서리)에 덮어쓰기 (PNG).
> 전부 넣은 뒤 Claude를 부르면 WebP 변환 + 최종 검수를 진행한다.
>
> - 배경: **가로(landscape)** 로 생성. 크기는 아무거나 (변환 시 780×660으로 맞춤)
> - 악세서리: **정사각 + 배경 투명** 필수. "배경은 완전히 투명" 문구를 빼먹지 말 것
> - 샘플로 승인된 bg_sunny / bg_galaxy / acc_crown 세 장과 같은 톤을 유지하는 게 목표
